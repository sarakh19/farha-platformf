# Farha – Children's Events Platform

Farha is a web platform developed as a graduation project at the University College of Applied Sciences (UCAS).

The platform aims to make it easier for parents in Gaza to discover children's activities and events in one place.

It also provides organizations with a way to publish their events and manage registrations.

## Project Goals

- Help parents discover activities suitable for their children.
- Make event information easier to access.
- Allow organizations to publish and manage children's events.
- Simplify the event registration process.

## Technologies

The project was developed using Laravel and PHP, with frontend interfaces and database integration.
